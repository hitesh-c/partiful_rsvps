Profile Basics

Dropdown Fields
How matching works
  • Label matchers are compared with the question text shown on the Partiful form. The field name is only for you — it is never matched.
  • Matching is loose: case, punctuation and the trailing * are ignored, and it counts as a match if either text contains the other. job title matches “What is your job title? *”.
  • The option is picked loosely too: Founder selects “Founder / CEO”. Fallbacks are tried in order if the preferred option isn’t offered.
  • Use short, distinctive phrases and list several phrasings separated by commas. Very short matchers (like name) can hit the wrong question.
  • A field with an empty preferred option is skipped.

Choose your preferred answer for dropdown questions. Each field matches a question by its label and selects the preferred option.

Custom Question Fields
How matching works
  • The pattern is compared with the question text shown on the Partiful form. Case, punctuation and the trailing * are ignored.
  • Exact: the whole label must equal the pattern. Contains is loose — it matches if either text contains the other. Regex is tested against the raw label, case-insensitive.
  • These fields are checked first, before dropdown fields and your profile details, so keep patterns specific.
  • A field with an empty answer is skipped.

Handle host-specific prompts. Supports exact, contains, or regex label matches.
